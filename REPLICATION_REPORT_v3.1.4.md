## 2. Advanced PDF Manual Split & "Subtract" Logic
This is a sophisticated feature allowing users to surgically remove pages from a master PDF and treat them as separate print jobs.

### Feature Details:
- **Trigger:** Double-click a row in the File Queue `TableView`.
- **Viewer Enhancements:**
  - Added a "Style" ComboBox (Simplex/Duplex/Booklet) inside the PDF Viewer.
  - Added a "Split & Remove" (Subtract) checkbox.
- **Persistence:** Split parts are saved as `Split_[OriginalName]_Part_[Start]-[End].pdf` in the same directory.
- **Subtract Logic:**
  1. The selected range is extracted and added to the queue as a new `FileItem`.
  2. The original file is modified using `pdfService.removePages(file, start, end)`.
  3. The modified master file is renamed to `Remain_[OriginalName]`.
  4. Rules (Printer, Copies, Style) are re-evaluated for the remaining file based on its new content/page count.

### Implementation Hint (Java/PDFBox):
```java
public File removePages(File file, int startPage, int endPage) throws IOException {
    try (PDDocument document = Loader.loadPDF(file)) {
        PDDocument newDoc = new PDDocument();
        int total = document.getNumberOfPages();
        for (int i = 1; i <= total; i++) {
            if (i < startPage || i > endPage) {
                newDoc.importPage(document.getPage(i - 1));
            }
        }
        if (newDoc.getNumberOfPages() == 0) { newDoc.close(); return null; }
        File tempFile = File.createTempFile("remaining_", ".pdf");
        newDoc.save(tempFile);
        newDoc.close();
        return tempFile;
    }
}
```

## 5. Connectivity & Security (SSL Bypass)
To handle downloads from legacy university portals with expired/self-signed certificates, an insecure `HttpClient` was implemented.

### Implementation:
```java
private static synchronized HttpClient getInsecureHttpClient() {
    TrustManager[] trustAllCerts = new TrustManager[]{ new X509TrustManager() {
        public X509Certificate[] getAcceptedIssuers() { return null; }
        public void checkClientTrusted(X509Certificate[] certs, String authType) { }
        public void checkServerTrusted(X509Certificate[] certs, String authType) { }
    }};
    SSLContext sc = SSLContext.getInstance("TLS");
    sc.init(null, trustAllCerts, new java.security.SecureRandom());
    return HttpClient.newBuilder().sslContext(sc).followRedirects(HttpClient.Redirect.ALWAYS).build();
}
```
